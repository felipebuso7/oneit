# Checklist de release

- [ ] Backlog e changelog atualizados.
- [ ] Diff revisado e sem dados/segredos.
- [ ] Migrations auditadas e compatíveis.
- [ ] Lint, typecheck, testes e build executados.
- [ ] Smoke test e console/rede verificados.
- [ ] Commit e branch registrados.
- [ ] Deployment associado ao domínio confirmado.
- [ ] Rollback e bloqueios externos registrados.
